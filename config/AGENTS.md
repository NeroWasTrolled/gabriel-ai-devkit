# Global Engineering Guidance

- Preserve the user's requested scope and existing repository conventions.
- Inspect relevant code and dependencies before proposing structural changes.
- For defects, reproduce or gather evidence and identify the root cause before editing.
- Prefer the smallest change that fully solves the problem.
- Do not claim success without running the most relevant available verification.
- Treat external input as untrusted and avoid exposing secrets or sensitive logs.
- Ask before destructive operations, production changes, broad migrations, or large refactors.
- State assumptions, remaining risks, and checks that could not be run.
- Use a specialized skill only when its description matches the task.
