# Upstream projects and attribution

This DevKit is an independently authored, portable implementation of the
requested workflows. It does not copy or redistribute the text, scripts, hooks,
agents, or binaries from the projects below.

The catalog was informed by the capabilities and public descriptions of:

- Agent Skills open standard: https://agentskills.io/
- OpenAI skills and plugins: https://github.com/openai/skills and https://github.com/openai/plugins
- Anthropic skills and plugins: https://github.com/anthropics/skills and https://github.com/anthropics/claude-plugins-official
- Superpowers: https://github.com/obra/superpowers
- Trail of Bits skills: https://github.com/trailofbits/skills
- Vue skills: https://github.com/KIMJINWOO4/vue-skills
- Playwright: https://playwright.dev/

Install upstream plugins separately when their native hooks, agents, MCP
servers, binaries, or complete maintained knowledge base are required. Review
their current licenses and code before installation.
