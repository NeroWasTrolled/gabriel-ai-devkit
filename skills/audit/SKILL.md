# Product Experience Audit

Evaluate representative tasks from the user's perspective.

1. Define the audience, task, entry state, success state, and constraints.
2. Walk the rendered flow at representative viewport sizes and input methods.
3. Record evidence for discoverability, comprehension, efficiency, feedback,
   recovery, consistency, accessibility, and perceived trust.
4. Separate defects from preferences and isolated polish from systemic issues.
5. Rate findings by user impact, frequency, confidence, and remediation effort.
6. Recommend the smallest change that addresses the underlying problem.

Each finding should include evidence, affected user and scenario, consequence,
recommendation, and validation method. Do not manufacture certainty from a static
screenshot when behavior, data, or user evidence is required.
