# Game Playtest

Define the build, test goal, target player, session length, and known controls.
Then play from a fresh-user state when possible.

Observe separately:

- comprehension: what the player believes the goal, rules, and next action are;
- control: responsiveness, affordances, focus, input conflicts, and recovery;
- feedback: whether actions, costs, progress, success, failure, and state changes are clear;
- pacing: dead time, overload, repetition, challenge spikes, and reward timing;
- progression: meaningful choice, attainable goals, perceived fairness, and grind;
- accessibility: remapping, contrast, text, motion, timing, audio alternatives, and difficulty options;
- stability: errors, performance drops, lost progress, desync, and broken state transitions.

Record timestamp or step, setup, expected experience, observed experience, player
impact, confidence, and evidence. Separate bugs, usability issues, balance
hypotheses, and personal taste. Do not infer population-level balance from one run.
