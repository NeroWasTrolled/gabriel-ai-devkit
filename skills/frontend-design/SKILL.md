# Frontend Design

Translate the product's audience, purpose, content, and emotional tone into a
coherent visual system before styling individual screens.

- State a specific design direction and the few principles that make it recognizable.
- Build hierarchy through typography, spacing, composition, contrast, and density.
- Use a restrained token system for color, type, spacing, radius, elevation, and motion.
- Design real loading, empty, error, disabled, success, and responsive states.
- Make one or two memorable decisions; do not decorate every surface.
- Avoid generic AI-dashboard defaults unless they genuinely match the product.
- Preserve semantic HTML, accessibility, legibility, performance, and reduced motion.

Implement within the existing framework and design system. Verify the rendered
result at representative widths and correct visual problems observed in screenshots.
