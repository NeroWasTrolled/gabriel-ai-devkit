# Game UI Frontend

Use game-interface principles to improve attention, comprehension, feedback, and
motivation—not to decorate every screen.

- Establish the action hierarchy: primary objective, current state, available
  actions, consequences, and secondary detail.
- Match HUD persistence to decision frequency; hide information that is not useful now.
- Encode status through more than color and keep labels legible at real sizes.
- Use animation for meaningful transitions, rewards, danger, interruption, and
  causality; respect reduced motion and avoid continuous distraction.
- Make progress, cooldowns, locks, rarity, and costs understandable without lore knowledge.
- Design input states for mouse, keyboard, touch, controller-like navigation when relevant.
- Keep business-critical and destructive actions conventional and unmistakable.
- Test dense data, localization, small screens, latency, and repeated use.

Prefer a coherent visual language over isolated neon effects. A system should
feel responsive before it looks cinematic.
